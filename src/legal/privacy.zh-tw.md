本隱私權政策說明您使用 Tangent macOS App（下稱「Tangent」或「本 App」）、造訪本網站（tangent.nicraft.co）、下載或更新 Tangent 時，Nicraft（下稱「我們」）如何處理您的資料。Tangent 仍在持續擴充，因此本政策涵蓋整個產品，而不只是目前已有的功能。若新功能會改變我們處理的資料，我們會在該功能推出前更新本政策。

## 重點摘要

- 您的專案、對話、模型與各項設定都只留在您的 Mac，我們不會收到。
- Tangent 本身不附 AI 模型。您自行選擇模型來源；向 Agent 提出需求時，內容會從您的 Mac 直接送往該來源，不經過我們。
- Tangent 不儲存 API 金鑰或登入資料；您帶進來的模型來源各自保管自己的。
- Tangent 沒有 Nicraft 帳號、沒有雲端同步，也沒有廣告或追蹤程式碼。
- Tangent 自己的伺服器只提供網站、安裝檔與更新檔，不會收到您的專案內容。

## 一、留在您 Mac 上的資料

Tangent 在本機運作。以下資料儲存在您的 Mac，不會傳送給我們：

- **專案**：每個專案的對話、模型程式碼、版本、網格與 STEP 檔、標註、顏色與材質，以及專案卡片的縮圖，都存在您「資料庫」（Library）檔案夾中的 Tangent 檔案夾。這些資料沒有經過 Tangent 另外加密。
- **附件**：您附加的圖片、PDF 與文字檔只在 Tangent 開啟期間存放於記憶體，不會隨專案儲存。重新開啟 Tangent 後，先前的訊息只保留檔名，不保留檔案。
- **偏好設定**：例如語言、模型來源與其選項、App 圖示，儲存在您的 Mac。
- **匯出檔案**：匯出的檔案存放在您選擇的位置。「在 Bambu Studio 開啟」會把 3MF 檔寫入您 Mac 上 Tangent 的快取，再用 Bambu Studio 開啟。

Tangent 不是備份服務，重要資料請另行匯出或備份。

## 二、模型來源與 Agent

Tangent 的 Agent 由您選擇並設定的模型來源驅動：您 Mac 上的命令列工具（例如 Claude Code、Codex）或本機模型伺服器（例如 Ollama、LM Studio）。Tangent 本身沒有模型，也不保管任何金鑰：各工具使用它自己的登入。

**傳送的內容**：每次送出訊息，Tangent 會把這一輪 Agent 需要的內容送往您選擇的來源：

- 您的訊息，以及它能讀取的附件（圖片、PDF、文字檔與 SVG 原始碼）；
- 專案對話中先前的訊息；
- 目前模型的程式碼；
- 您在模型上選取的部位，包括名稱、位置、方向與尺寸；
- 您的標註，包括內容與位置；
- Tangent 的指示與內建的 CAD 建模知識。

若程式碼建構失敗，錯誤訊息會送回同一個來源讓它修正。連結、影片、CAD 檔等無法讀取的附件，Agent 只會收到名稱；Tangent 不會下載您附加的連結所指向的網頁。

**送往何處**：內容會從您的 Mac 直接送往您選擇的來源。命令列工具會以您登入的帳號，送往該工具自己的服務；本機模型伺服器會把內容留在您的 Mac，或您指定的那台電腦。

**由誰處理**：我們不會收到、儲存或看到這些內容。您選擇的來源會依其自身的條款與隱私權政策處理，包括是否保留您的請求或用於訓練模型。傳送任何機密內容前，請先確認該服務商的設定與政策。若不希望設計離開您的 Mac，請使用本機模型伺服器。

## 三、macOS 權限

Tangent 目前不會請求輔助使用、螢幕錄製、相機或麥克風等特殊 macOS 權限。它只在您附加檔案時讀取檔案，也只在您匯出時把檔案寫到您選擇的位置。日後若有功能需要權限，App 會在請求時說明用途。

## 四、Tangent 何時會連上網路

- **模型來源**：詳見第二節。
- **幾何引擎準備**：Tangent 的幾何引擎不在安裝檔內。首次啟動 Tangent，以及更新改變了引擎之後，Tangent 會用 uv 在您的 Mac 上建立引擎。若您的 Mac 沒有合適的 uv，Tangent 會先從 GitHub 下載自己版本固定的 uv，並且只在它符合 App 內建的檢查碼時才使用。接著 uv 會從 Python Package Index 下載引擎所需、版本固定的開源元件（例如 build123d）；若您的 Mac 沒有合適的 Python，也會從 GitHub 下載 Python 執行環境。這些服務會收到一般下載都會帶有的資訊，例如您的 IP 位址。專案內容不會因此傳出。
- **連結**：Agent 回覆中的連結，只在您點選時以網頁瀏覽器開啟。
- **更新**：啟動後幾秒，之後每天一次，Tangent 會向 tangent.nicraft.co 要一個說明最新版本的小檔案。這個請求不帶任何關於您或您 Mac 的資料：沒有識別碼、沒有版本，也沒有專案內容。您可以在設定中關閉自動檢查。有新版時，Tangent 會在背景從 download.nicraft.co 下載，用 App 內建的金鑰驗證簽章，通過後才替換自己。這些伺服器會收到一般請求都會帶有的資訊，例如您的 IP 位址。
- **當機報告與使用分析**：Tangent 目前不傳送當機報告或使用分析。日後若加入，會先在此說明，且絕不包含您的對話、附件或模型。

Agent 撰寫的模型程式碼，會在您 Mac 上無法連網的沙盒中執行。

## 五、網站與下載

- **網站**：我們使用 Microsoft Clarity 了解訪客如何使用本網站。Clarity 會設定 Cookie，並記錄您與網頁的互動，例如點擊、捲動與滑鼠移動，以及裝置與瀏覽器類型、大略所在地區；您在表單中輸入的文字會被遮蔽。Microsoft 依其隱私權聲明處理這些資料。若您選擇了佈景主題，瀏覽器會把選擇記在它自己的儲存空間，不會傳送給我們。網站代管服務商會處理傳送網頁與維護安全所需的技術資料，例如 IP 位址、瀏覽器類型與造訪的頁面。
- **下載**：安裝檔與更新檔由 download.nicraft.co 提供。我們的儲存服務商會處理傳送檔案與維護安全所需的技術資料，例如 IP 位址與所要求的檔案。下載 Tangent 不需要您的電子郵件地址或帳號。

## 六、服務商

我們只與協助營運 Tangent 的服務商分享資料，且只提供各自所需的部分。目前包括：

- **Vercel**：網站代管，包含告知新版本的檔案。
- **Cloudflare**：安裝檔與更新檔的儲存與傳送。
- **Microsoft Clarity**：網站使用分析。

新增服務商時，我們會加進這份清單。我們不會出售您的個人資料，也不會為廣告目的分享。

您選擇的模型來源（第二節）與幾何引擎的下載來源（第四節）不是我們的服務商：是您的 Mac 直接連線到它們，我們不會與它們分享資料。

依法令要求，或為保護使用者、我們或他人的權利、安全與資訊安全所必要時，我們也可能提供資料。

## 七、處理依據

在適用 GDPR（歐盟與英國）等需要法律依據的地區，我們的依據如下：

- **履行與您之間的契約**：提供 App。
- **我們的正當利益**：維護 Tangent 的安全與運作，並了解產品需求。
- **您的同意**：需要同意的選用功能。
- **法律義務**：例如稅務與會計紀錄。

適用中華民國《個人資料保護法》時，我們只在本政策所述的特定目的範圍內蒐集、處理及利用個人資料。

## 八、跨境傳輸

我們的服務商可能在您所在地以外的國家處理資料，包括美國。依法需要時，我們會採取適當的保護措施，例如標準契約條款。

## 九、保存期間

- **您 Mac 上的資料**：由您掌控，保留到您刪除專案或移除 App 資料為止。
- **送往模型來源的資料**：依該服務商的政策與您在該服務的設定保存，我們不保留副本。
- **服務商的技術紀錄**：依各服務商設定的有限期間保存。

## 十、您的權利

依您所在地的法律，您可能有權：

- 查詢、閱覽或取得資料副本；
- 補充或更正資料；
- 刪除資料；
- 要求停止或限制蒐集、處理或利用；
- 以可攜格式取得資料；
- 隨時撤回同意。

請寄信至 contact@nicraft.co 提出請求。我們可能需要確認請求確實來自您本人，並會在法律規定的期限內回覆。部分資料可能須依法保存。您送往模型來源的內容，我們無法存取或刪除，請直接向該服務商提出。您也可以向當地的個人資料保護主管機關提出申訴。

## 十一、資訊安全

我們採取合理的技術與管理措施保護資料。在 App 中，更新會用 App 內建的金鑰驗證，幾何引擎只接受 Tangent 本身的請求，模型程式碼在沙盒中執行。對於我們持有的資料，我們使用加密連線，並限制可存取這些資料的人員。任何傳輸或儲存方式都無法保證絕對安全。若發生影響您的資料事故，我們會依法通知您。

## 十二、兒童

Tangent 不以未滿 13 歲（或您所在地法律規定之最低年齡）的兒童為對象，我們也不會在知情的情況下蒐集他們的個人資料。各模型來源另有其最低年齡規定。若您認為有兒童向我們提供了資料，請與我們聯絡，我們會將其刪除。

## 十三、政策更新

我們會隨 Tangent 與法令的變化更新本政策，頁首日期即為最新版本。若為重大變更，例如新的資料類別或新的使用目的，我們會在生效前於本網站或 App 內公告。依法需要您同意時，我們會徵求您的同意。
